Device backup and restore

Use a full backup before clearing browser data or moving to another device. It contains all saved configurations and reusable furniture from this device.

About local storage

The app itself is served by GitHub Pages, but saved data stays in this browser on this device. Private/incognito browsing, clearing site data, or browser cleanup can remove it. Export a full backup periodically if the layouts matter.

Getting Started

  1. 1. ScaleUse Scale if you want to improve the floor-plan calibration.
  2. 2. Add furnitureUse + Furniture to choose a saved piece or create a new one.
  3. 3. ArrangeDrag furniture on the map. Select a piece to Rotate, Edit, Copy, or Delete it.
  4. 4. SaveOpen Layout, give the arrangement a name, and save it on this device.
